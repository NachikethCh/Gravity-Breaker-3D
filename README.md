# GRAVITY BREAKER

A 3D gravity-shifting ninja runner set inside a futuristic tower. Switch between the tower's surfaces, dodge hazards, collect energy shards, and fight your way toward the summit.

## 🎮 Play the Game

**Playable itch.io page:** https://nachikethch.itch.io/gravity-breaker-3d

Download the build for your platform from the itch.io page. The game is currently distributed as downloadable Windows and Linux ZIP files.

## ✨ Features

- Gravity-shifting movement across the floor, walls, and ceiling
- Increasing running speed and stamina-based boosting
- Futuristic tower sectors with lasers, spikes, crushers, rotating hazards, and energy mines
- Collectibles, checkpoints, score tracking, and saved best score
- A final Tower Guardian encounter

## 🕹️ Controls

| Action | Controls |
| --- | --- |
| Strafe | `A` / `D` |
| Jump | `Space` |
| Flip gravity | `Q` |
| Boost | `W` / `Shift` |
| Brake | `S` / `Ctrl` |
| Pause / resume | `Esc` |

**Gravity direction shortcuts:** Hold `A` and press `Q` to advance the surface sequence; hold `D` and press `Q` to reverse it. Gravity flipping has a cooldown.

## 🖥️ Download and Run

1. Open the [GRAVITY BREAKER itch.io page](https://nachikethch.itch.io/gravity-breaker-3d).
2. Download the ZIP for your operating system.
3. Extract the ZIP.
4. Run the included game executable.

If the game does not launch, check that the ZIP was fully extracted and that all files included in the archive remain together.

## 🛠️ Development

- **Engine:** Godot 4.7.2
- **Language:** GDScript
- **Genre:** 3D action / endless runner

To open the project in Godot, download or clone this repository, then import the folder containing `project.godot` using Godot 4.7.2.
