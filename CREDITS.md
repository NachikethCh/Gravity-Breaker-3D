## Original project elements

The following elements were created procedurally in the project: the four-surface tunnel grid, sector gates, spikes, laser gates, crushers, rotating blades, energy mines, energy shards, Guardian meshes and core targets, HUD/menu layouts, and the GRAVITY BREAKER icon artwork.

## Engine

GRAVITY BREAKER is built with the Godot Engine. Godot is not bundled as a separate application in this source project; desktop exports are generated using the Godot export templates.
